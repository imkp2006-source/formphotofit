Use the official notification as the source of truth

SSC and UPSC application requirements can vary by examination, application year, and notification. The settings shown here are practical starting points, not a guarantee of the current official requirement. Before uploading, compare the dimensions, file size, format, and signature instructions with the current notification.

Common starting settings used on this page

  • Photo: 200 × 230 px and under 50 KB is a practical starting point for the tool.
  • Signature: a compact signature target such as under 20 KB can be a useful starting point.
  • Format: use the exact image format accepted by the current portal.
  • Background: follow the current notification rather than assuming one background works for every application.

Step-by-step: prepare your SSC or UPSC files

  1. Read the current official notification and note every photo and signature constraint.
  2. Choose the closest FormPhotoFit preset from this page.
  3. Upload the image, then adjust dimensions or target KB if the official values differ.
  4. Process and review the output.
  5. Verify the final file against the official portal before submitting.

Common mistakes on exam application uploads

  • Using an old year’s requirements without checking the current notification.
  • Meeting the KB limit but missing the required dimensions.
  • Uploading the correct photo but the wrong signature format or size.
  • Relying on a generic “passport photo” specification instead of the exam’s own instructions.

What is the SSC photo size?

A 200 × 230 px photo under 50 KB is used as a practical starting point on this page, but SSC requirements can vary by examination and notification. Confirm the current official specification before submitting.

What is the UPSC photo size?

UPSC application requirements can vary by notification and application flow. Use the current official instructions as the source of truth, then use FormPhotoFit to create the required dimensions and file size.

Can I prepare the photo and signature on the same website?

Yes. FormPhotoFit lets you switch between photo and signature presets in the same browser-based tool.

Does FormPhotoFit verify that my SSC or UPSC upload will be accepted?

No. The tool checks the settings you choose and provides technical feedback, but only the official application portal determines whether a submission meets its requirements.
